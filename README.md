# Frontend Code – HTML & CSS

This project is a simple frontend website developed using **HTML** and **CSS**. It focuses on creating a clean, responsive, and user-friendly interface. The project includes multiple sections such as Home, About, Skills, Projects, and Contact, designed to demonstrate basic frontend development concepts.

## Features
- Responsive layout using HTML and CSS  
- Clean and simple UI design  
- Navigation between multiple sections/pages  
- Styled buttons, cards, and content sections  
- Organized folder structure  
- Beginner-friendly code  

## Technologies Used
- HTML5  
- CSS3  

## Project Structure

project-folder/
│── index.html
│── about.html
│── skills.html
│── project.html
│── contact.html
│── style.css
│── images/


## How to Run
1. Download or clone the repository  
2. Open the project folder  
3. Double-click `index.html`  
4. The website will open in your browser  

## Purpose
This project is created to practice **basic frontend development** using HTML and CSS, including layout design, styling, and page navigation.
