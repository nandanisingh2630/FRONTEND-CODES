
# All Frontend Code (HTML & CSS)

This repository contains basic frontend programs developed using **HTML** and **CSS**. These files demonstrate different web design concepts such as forms, tables, CSS styling methods, and page layout. The project is useful for beginners to understand fundamental frontend development.

## Files Included

- `csshtml.html` – HTML page with CSS styling  
- `externalcss.html` – Example of external CSS usage  
- `INTERNALCSS.html` – Example of internal CSS styling  
- `form.html` – HTML form design  
- `table.html` – Table creation using HTML  
- `properties.html` – CSS properties demonstration  
- `EX.css` – External CSS stylesheet  

## Features
- Basic HTML structure examples  
- Internal, External, and Inline CSS  
- Form design using HTML  
- Table creation and styling  
- CSS properties and formatting  
- Beginner-friendly frontend practice files  

## Technologies Used
- HTML5  
- CSS3  

## How to Run
1. Download or clone this repository  
2. Open the folder  
3. Select any `.html` file  
4. Double click to open in browser  

## Purpose
This repository is created for practicing **basic frontend development** concepts using HTML and CSS. It includes multiple examples to understand styling techniques and webpage structure.
